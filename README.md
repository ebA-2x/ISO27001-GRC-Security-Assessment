# ISO 27001:2022 Security Controls Assessment

## Project Overview

This project demonstrates a simulated internal security controls assessment for Northstar Technologies, a fictional organization with 75 employees.

The assessment evaluates eight selected ISO/IEC 27001:2022 Annex A controls, with a focus on identifying security control gaps, reviewing audit evidence, and recommending corrective actions.

**Disclaimer:** This is an independent educational portfolio project. All company information, findings, and audit evidence are fictional. It is not an official ISO 27001 audit or certification.

## Assessment Scope

The assessment covers:

- Access control and access rights
- Security awareness training
- Endpoint security and malware protection
- Technical vulnerability management
- Security logging and monitoring

## Methodology

The assessment follows a simulated internal review process:

1. Identify the applicable ISO 27001 security controls.
2. Define the evidence required to assess each control.
3. Review fictional evidence against established security requirements.
4. Document identified gaps and associated risks.
5. Recommend remediation activities and establish tracking procedures.

## Project Deliverables

| Deliverable | Description |
|---|---|
| Control Assessment Workbook | Assessment of eight security controls, including findings and supporting evidence |
| Final Assessment Report | Summary of the assessment methodology, identified risks, and recommendations |
| Simulated Evidence Register | Record of fictional audit evidence reviewed during the assessment |

## Tools and Skills Demonstrated

Microsoft Excel, ISO 27001 control mapping, security compliance assessments, audit evidence documentation, risk prioritization, and remediation tracking.
